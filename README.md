#Projetos-Pessoais
Olá, caro leitor! Seja bem vindo ao meu repositório de **Projetos Pessoais**.

##📦 O que colocarei aqui?
Como o nome indica, aqui será o local em que armazenarei qualquer projeto meu, seja ele individual ou coletivo, simples ou mais complexo. 

##🖥️ Quais linguagens serão usadas aqui?
Ainda estou iniciando no mundo da programação, então espere bastante as seguintes linguagens:
* Python (grande maioria dos arquivos);
* JavaScript (*ainda estou aprendendo*, demorará um tempo até aparecer em um projeto).

##📄 O que estará nesses arquivos?
Os arquivos serão compostos por códigos feitos para resolver um problema ou feitos por pura curiosidade para criar algo novo,
como uma calculadora básica, um sistema bancário simples, etc. Ao longo do tempo, vou aprendendo mais coisas e, consequentemente,
meus projetos ficarão mais complexos.
